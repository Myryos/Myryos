# Herve Boutonnet

Je fais du développement backend, surtout en Python et Django. Ces trois dernières années, j'ai partagé mon temps entre le code et l'administration système.

Au CFPP, je me suis occupé de la refonte du site. J'ai pensé l'architecture et monté la base : une API Django REST, un front en Nuxt, la CI et des environnements de staging. À côté, je gérais le réseau (Sophos, RADIUS, VoIP) et Microsoft 365.

En ce moment, je me forme à TypeScript, NestJS et Next.js, et je remets au propre mes anciens projets de formation.

Je cherche un poste de développeur backend ou full-stack, du côté de Lyon ou en full remote, et je suis disponible dès maintenant.

## Avec quoi je travaille

Côté backend, Python, Django, Django REST Framework, Flask et Node.js. Côté front, Vue, Nuxt, React et JavaScript. Pour les données, PostgreSQL, Redis, MySQL et MongoDB. Je teste avec Pytest, Jest et Selenium.

J'utilise Docker, Git et GitHub Actions, et j'ai mon propre VPS où tournent n8n et Gitea.
